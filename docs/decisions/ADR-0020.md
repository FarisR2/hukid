# ADR-0020 — Lectura base aislada del dashboard

- Estado: aceptado para laboratorio DASH-T02, 2026-11-06.
- Alcance: [FEAT-003](../features/FEAT-003-dashboard/spec.md), caso de uso y persistencia; sin HTTP/UI.

## Contexto

DASH-T01 fija conteos, actividad, privacidad y autorización antes de agregar. AUTH/USR almacenan membership, revisión, roles/scopes y auditoría. Sus credenciales escriben o tienen otro propósito. No existen ownership issuer ni atribución issuer en auditoría.

## Decisión

Añadir store con credencial hukid_dashboard_runtime separada, SELECT mínimo y RLS tenant/allowlist mediante migración aditiva 0011. Revalidar contexto y consultar en una transacción READ ONLY / REPEATABLE READ; comprobar capacidades antes de las fuentes. No compartir el pool de escritura ni ampliar roles. OpenRuntimePool rechaza credenciales combinadas.

Conectar sólo conteo snapshot de memberships activas y proyección acotada de auditoría tenant. Conservar precedencia permiso→disponibilidad para fuentes futuras. Sin ownership confiable, fallar cerrado para selectores/conjuntos issuer que lo requieran; no atribuir eventos tenant a emisores. La [referencia de lectura](../03-design/console-dashboard-reads.md) mantiene detalle de puertos, errores, índice y pruebas.

Mantener callback de actividad dentro del snapshot para que DASH-T03 autentique posición/asOf/deadline contra revisión y scopes vivos antes de leer filas. Este incremento no entrega un cursor público ni toma Position como autoridad cliente.

## Consecuencias

El rol de lectura no puede mutar datos, leer secretos o emitir auditoría de negocio. La reautorización es por snapshot; un cambio concurrente se observa en la siguiente lectura. Fallos de autorización o de la única fuente conectada no se ocultan con ceros. El índice corresponde al predicado/orden concreto; no demuestra carga ni fija SLA.

DASH-T03 mantiene handlers, BFF, configuración de credencial, cursor autenticado y observación HTTP; DASH-T04 interfaz. Perfil draft, bloqueos productivos, dominios HK, atribución/ownership issuer y grants futuros no cambian.
