# ADR-0022 — Interfaz base del dashboard y roles de contexto

- Estado: aceptada para el laboratorio DASH-T04.
- Fecha: 2026-11-06.
- Alcance: Console React y respuesta de contexto BFF/Management. No cambia grants ni fuentes.

## Contexto

AC01 exige nombre, rol y navegación autorizada desde /me; el DTO existente sólo exponía capacidades, scopes y revisión. DASH-T03 ya proporciona overview y actividad con autorización viva, filtros UTC y cursor autenticado. La UI debe evitar mezclar respuestas al cambiar organización o filtros y expresar disponibilidad sin inventar métricas.

## Decisión

1. Añadir roles al contexto desde la misma lectura de membresía que deriva capacidades. Campo aditivo opcional en schema; el servidor actual siempre lo emite. Los inputs y la autoridad de autorización siguen intactos.
2. Mantener una sola página con navegación mediante enlaces a secciones, capacidades reales y controles de sesión existentes. No crear rutas a módulos futuros.
3. Separar las lecturas overview/actividad para recuperar fallos por región. No consultar actividad sin audit:read. Usar únicamente BFF, sin tokens Bearer en navegador ni persistencia local de datos.
4. Desmontar por actor/tenant/revisión/capacidades/scopes y cancelar/verificar cada generación de filtros. 401 vuelve al login; 403/404 revalida identidad sin bucle y deja reintento explícito.
5. Reutilizar diseño/tokens AUTH/USR; mostrar fuentes, periodo, generatedAt/asOf y estados textuales. Las fuentes inexistentes permanecen ausentes o sin autorización según contrato.

## Consecuencias y límites

Un consumidor con schema estricto anterior debe actualizar su schema para aceptar roles; no se eliminan ni reinterpretan campos existentes. No se deducen roles desde capacidades ni se modifica la matriz de USR. No requiere migración ni amplía credenciales runtime.

El laboratorio verifica UI con BFF/IdP/DB propios y fixtures de fallo explícitos. Dominios issuer/definition/issuance/status, ownership confiable, gate completo, carga, CI remoto y producción siguen pendientes. La interfaz no prueba emisión/verificación de credenciales ni conformidad del perfil draft.
