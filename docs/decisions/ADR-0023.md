# ADR-0023 — Reloj de fuente para la vigencia del overview

- Estado: aceptada para la corrección de laboratorio DASH-T04.
- Fecha: 2026-11-06.
- Alcance: marcas temporales del overview base PostgreSQL; sin cambio de JSON, permisos o persistencia.

## Contexto

El pipeline Windows rechazó lecturas válidas del dashboard con 503. La reproducción local observó transaction_timestamp() de PostgreSQL 161,6 microsegundos por delante del time.Now de Go utilizado para generatedAt. SourceSection rechaza correctamente observaciones futuras, pero comparaba dos relojes de proceso distintos. Las validaciones locales previas no habían reproducido esa diferencia intermitente.

## Decisión

El puerto Snapshot proporciona GeneratedAt desde el reloj de la fuente. Para la base actual, el adaptador consulta clock_timestamp() después del conteo y dentro de la misma transacción READ ONLY / REPEATABLE READ autorizada. El asOf conserva transaction_timestamp(). La composición compara ambas marcas del mismo reloj PostgreSQL.

No se añade tolerancia a datos futuros, no se corrige una fecha con max/asOf y no se reintentan lecturas para ocultar el error. Fallos del reloj de fuente, datos sin observación y observaciones posteriores a generatedAt siguen fallando cerrados. Frescura y estados conservan sus reglas.

El reloj de aplicación sigue validando ventanas y controlando asOf/deadline/TTL del cursor de actividad. Esta corrección no desplaza expiraciones de autorización/sesión ni cambia cursores. La regla de fuente actual no promete un snapshot o reloj común con dominios futuros.

## Consecuencias y verificación

Overview añade una consulta de reloj sin datos protegidos a su snapshot, después de la autorización; no añade privilegios, migraciones ni escrituras. El contrato de respuesta mantiene los mismos campos, tipos y estados. generatedAt identifica la composición respecto del reloj PostgreSQL de la fuente base.

Las pruebas unitarias fijan relojes distintos, disponible/stale, observación futura y fallo de reloj. Una prueba PostgreSQL fija el reloj de aplicación en 2020 y repite cien lecturas actuales para comprobar conteo/asOf/generatedAt coherentes sin depender de carreras o sleeps. La regresión real HTTP y el gate conservan los checks de permisos y aislamiento.
